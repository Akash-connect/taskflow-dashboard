# TaskFlow - Task & Team Management Dashboard

A modern responsive Task & Team Management Dashboard built using Next.js, TypeScript, Tailwind CSS, and Context API.

## Features

- Login page with form validation
- Forgot password page with form validation
- Dashboard statistics
- Task management module
  - Create task
  - Edit task
  - Delete task
  - Search tasks
  - Filter by status
  - Filter by priority
  - Pagination
- Team members module
  - View team members
  - Add new members
  - Delete members
  - Display role and email
- Dark and light theme toggle
- Glassmorphism modern UI
- Responsive design for desktop, tablet, and mobile
- Context API state management
- Mock local data

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React Context API
- Lucide React Icons

git clone https://github.com/Akash-connect/taskflow-dashboard.git
